# Mini Project JavaScript

Kumpulan mini project JavaScript yang saya buat sebagai bagian dari proses belajar dan memahami dasar-dasar JavaScript.

Project ini berisi beberapa aplikasi sederhana yang menggunakan **HTML, CSS, dan JavaScript** tanpa menggunakan framework JavaScript.

## 🚀 Projects

### 1. Calculator
Aplikasi kalkulator sederhana untuk melakukan operasi matematika dasar.

**Fitur:**
- Penjumlahan
- Pengurangan
- Perkalian
- Pembagian

### 2. Color Picker App
Aplikasi sederhana untuk memilih warna dan melihat nilai warna yang dipilih.

**Fitur:**
- Memilih warna
- Menampilkan nilai warna
- Interaksi menggunakan JavaScript

### 3. Countdown Timer
Aplikasi penghitung waktu mundur.

**Fitur:**
- Mengatur waktu
- Countdown secara real-time
- Menampilkan waktu yang tersisa

### 4. Random Quote Generator
Aplikasi yang menampilkan kutipan secara acak.

**Fitur:**
- Menampilkan random quote
- Mengganti quote dengan tombol
- Menggunakan JavaScript untuk mengatur data dan interaksi

## 🛠️ Technologies

Project ini dibuat menggunakan:

- HTML5
- CSS3
- JavaScript
- Git & GitHub
